Cara memasang

  1. Jalankan installer yang baru diunduh. Pemasangan tidak memerlukan hak administrator.
  2. Bila muncul "Windows protected your PC", klik More info lalu Run anyway. Peringatan ini muncul karena installer Lapakin belum bertanda tangan digital.
  3. Bila Windows memblokir tanpa pilihan Run anyway, buka Windows Security → App & browser control → Smart App Control. Bila statusnya On atau Evaluation, bicarakan dengan pemilik laptop sebelum mematikannya, karena fitur itu tidak bisa dinyalakan kembali tanpa memasang ulang Windows.
  4. Cek keaslian berkas (opsional): di folder installer, buka PowerShell lalu jalankan Get-FileHash .\Lapakin-Setup-<versi>.exe. Hasilnya harus sama dengan kode cek di atas.

Setelah terpasang, versi berikutnya cukup diperbarui dari dalam aplikasi: Pengaturan → Pembaruan aplikasi → Cek update.
