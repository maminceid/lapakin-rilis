Kebijakan Privasi Lapakin

Berlaku sejak 6 November 2026

Ringkasan

Lapakin adalah aplikasi Windows untuk mengelola beberapa toko marketplace milik Anda atau klien Anda, masing-masing di profil browser yang terpisah. Semua data Lapakin disimpan di komputer Anda. Lapakin tidak memiliki akun pengguna, server, sinkronisasi cloud, iklan, maupun telemetri, dan penerbit Lapakin tidak menerima data Anda.

Data yang disimpan di komputer Anda

  • Data profil toko: nama, marketplace, warna, tag, alamat awal, status toko, dan pengaturan fingerprint per profil.
  • Catatan profil, username dan password login toko yang Anda simpan, serta username dan password proxy. Semuanya dienkripsi dengan kunci yang dilindungi Windows (DPAPI), dan juga dengan master password bila Anda mengaktifkannya.
  • Cookie, sesi login, dan data situs untuk setiap profil, disimpan terpisah per profil seperti di browser biasa.
  • Riwayat aktivitas di dalam aplikasi (misalnya profil dibuka atau diubah) dan hasil cek proxy.

Data yang dikirim keluar perangkat

  • Situs yang Anda buka. Profil membuka situs marketplace seperti browser biasa. Data yang Anda isi di situs tersebut diatur oleh kebijakan privasi marketplace itu sendiri.
  • Cek proxy. Saat Anda memeriksa proxy, Lapakin meminta alamat IP keluar ke layanan ipify melalui proxy tersebut. Lokasi IP dicari di database offline di komputer Anda, jadi tidak dikirim ke pihak lain.
  • Cek pembaruan (hanya installer dari situs Lapakin). Versi installer memeriksa rilis terbaru di GitHub saat Anda menekan Cek update. Versi Microsoft Store diperbarui oleh Microsoft Store dan tidak melakukan cek ini.

Selain itu Lapakin tidak mengirim, menjual, maupun membagikan data Anda kepada siapa pun.

Kendali Anda

  • Ubah atau hapus profil, login tersimpan, dan proxy kapan saja di dalam aplikasi.
  • Aktifkan master password untuk mengunci Lapakin.
  • Menghapus (uninstall) Lapakin versi Microsoft Store juga menghapus seluruh data Lapakin di komputer tersebut.

Anak-anak

Lapakin ditujukan untuk penjual dan pengelola toko, bukan untuk anak di bawah 13 tahun.

Perubahan dan kontak

Bila kebijakan ini berubah, versi terbaru diterbitkan di halaman ini dengan tanggal berlaku yang baru. Pertanyaan tentang privasi dapat dikirim ke business@naeva.id.

Privacy Policy (English summary)

Lapakin is a Windows app for managing your own (or your clients') marketplace stores in separate browser profiles. All data stays on your computer. Store logins, proxy credentials and notes are encrypted with a key protected by Windows (DPAPI) and, if enabled, your master password. Lapakin has no user accounts, servers, cloud sync, ads or telemetry. Data leaves your device only when profiles open the websites you choose, when you check a proxy (a request to ipify sent through that proxy), and, in the installer version only, when you check for updates on GitHub. Uninstalling the Microsoft Store version removes all Lapakin data. Contact: business@naeva.id.
